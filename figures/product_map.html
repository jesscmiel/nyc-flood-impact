What this is / isn’t

Earth2 precip = FCN + PrecipitationAFNO 6h accumulations.
Pluvial screening = USGS ~10 m terrain + NLCD/built proxy — not depth.
Impervious = NLCD 2021 percent impervious (~30 m) when available.
FEMA NFHL = static regulatory flood-hazard zones — not event inundation.
NWM / AHPS = channel high-flow / river-gauge context — not street flooding.
Demo drainage = OSM roads + catch basins sketch — NOT calibrated SWMM/DEP depths.
MRMS QPE = observed rainfall estimate (~1 km; not BREF).
311 = complaints, not surveyed floods.
